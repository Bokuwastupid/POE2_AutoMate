## Последний билд (эта сессия) — собран 0/0, в нём:
- Новая **UI-тема** (`App.xaml`) — палитра, кнопки, поля, чекбоксы, комбобоксы, табы, скроллбары. Имена контролов/хендлеры не тронуты.
- **ES-неуязвимость пофикшена**: прогресс по цели = падение эффективного HP (жизнь+ES). ES-моб/босс больше не считается «неуязвимым».
- **Ложный boss-kill пофикшен**: убийство подтверждается только если босс сначала виделся живым (Health>0), потом мёртвым. Лог один раз.
- **Exile ≠ босс**: `IsMapBoss` (требует «Boss»/«MapBoss» в metadata) для завершения карты; Rogue Exile (unique) больше не триггерит «карта готова».
- **dormant/event-locked мобы** игнорятся (нет читаемого живого HP), пока не активируются.
- **Atlas graph-выбор**: карта выбирается только среди **связанных ребром** с текущей нодой; reference = маркер → последняя пройденная нода; маркер переопределяется при протухании.
- **Boss rush**: босс убит → выход из карты (не доклиривает трэш).
- **Portal wait**: ждать 5с до первого клика по порталу + ретрай увеличен 2.2с→7с (чинит цикл из 8 быстрых попыток во время загрузки).
- **Глобальный троттл ввода** (~90мс, анти-кик-дисконнект).
- **Приоритет целей**: ближайшая ценная (Rare/Unique/Boss/Encounter), unique ближе rare → unique.
- **Reachable-only explore** + directed boss-seek (вглубь карты от входа) + детект арены по тайлам (`Arena`/`Boss`).

## Ключевые файлы
- `src/Core/Game/GameReader.cs` — чтение памяти, снапшот, `Categorize` (фильтры сущностей), инвентарь, atlas/landmark/ui API, ES в `ReadEntityLife`/`EntityData`.
- `src/Core/Game/Poe2AtlasNodes.cs` — ноды атласа + граф связей (`_connections`/`ConnectionsSnapshot`) + маркер current-ноды.
- `src/Core/Game/Poe2UiGeometry.cs` — проекция UI в экран, поиск кнопок (Traverse), детект грида.
- `src/Automation/AutoMapper.cs` — стейт-машина hideout→map (Prepare/SelectMap/Activate/EnterPortal/WaitForMap/ClearMap), boss-state, portal-логика.
- `src/Automation/CombatBot.cs` — бой/движение/лут/таргетинг, boss-state, explore (`PickGlobalExploreWaypoint`), фильтры (`IsCombatMonster`/`ShouldIgnoreTargetMetadata`/`IsMapBoss`).
- `src/Automation/RoutePlanner.cs` — A* по walkable-terrain.
- `src/POE2_AutoMate/App.xaml` — тема/стили. `MainWindow.xaml(.cs)` — layout + live loop + провайдеры.
